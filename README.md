# Agente de Suporte KSI

> **Repositório vitrine.** Apenas apresentação do projeto. O código-fonte é privado. Autor: Caio Alba de Camargo.

Agente de IA para apoiar o suporte do sistema KSI: responde dúvidas dos usuários com base em uma FAQ e em vídeos de treinamento.

## O que faz
- Responde perguntas frequentes sobre o sistema, com base em conteúdo curado.
- Usa transcrição de vídeos de treinamento (Whisper) como fonte de conhecimento.
- Reduz chamados repetitivos e acelera o atendimento.

## Contexto
Construído no trabalho com apoio de IA, como parte da automação do suporte de TI. Dados e conteúdo internos não são publicados.
